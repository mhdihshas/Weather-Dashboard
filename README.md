# 🌤️ Weather Dashboard

A modern and responsive weather dashboard application built with **Next.js, React, TypeScript, and Tailwind CSS**. The application provides real-time weather information by integrating with weather APIs and presents data through a clean, intuitive user interface.

This project was developed to practice modern frontend development, API integration, responsive design, and building real-world web applications.

# ✨ Features

## 🌍 Real-Time Weather Data
- Search weather information by city/location
- Display current weather conditions
- Show temperature, humidity, wind speed, and weather status
- Dynamic updates using external weather APIs

## 🔎 Location Search
- Search weather for different locations
- User-friendly search interface
- Real-time API data fetching

## 📱 Responsive Design
- Fully responsive layout
- Optimized for:
  - Desktop
  - Tablet
  - Mobile devices

## 🎨 Modern User Interface
- Clean dashboard-style design
- Weather-based visual elements
- Smooth user experience

## ⚡ Performance
- Built with Next.js optimization features
- Fast loading and efficient rendering
- Component-based architecture
